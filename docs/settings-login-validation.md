# 设置菜单与禅道账号登录验证

设置窗口左侧新增「通用设置」「外部同步」。原有设置归入通用，禅道与 TAPD 位于外部同步；切换不销毁表单，保留草稿，支持方向键/Home/End 导航。

禅道界面保存登录用户名、密码，host 通过 v1 Token 接口登录；单次操作内缓存 Token，HTTP 401/403 时重登并最多重试一次。用户名可回显，密码不回显、不进入状态接口及任务导出。用户名与同步处理人分别配置。旧 Token 配置不再读取或迁移，必须重新配置用户名密码。密码仍保存在 host 专用明文配置，未引入系统密钥库。

变更源文件：`SettingsModal.tsx`、`ExternalSyncPanel.tsx`、中英文词典、`styles.ts`、共享外部模型、`external-providers.ts`、`external-config.ts`、`external-sync.ts`、`zentao.ts`。对应 `lib/` 由构建生成。

验证：类型检查通过；低并发全量回归 **36 个测试文件、457 项通过**；新增登录测试覆盖登录体、Token 复用/失效重登、错误脱敏、密码保存恢复和来源身份兼容。真实 HTTP 模拟贯通登录、查询、同步、恢复；界面测试覆盖分类切换、键盘操作和草稿保留。Chrome 1000px/520px 检查了实际 SettingsModal 组件、左侧菜单、通用/外部页面及用户名密码字段，无脚本错误，窄屏无水平溢出。

边界：浏览器使用模拟 API，未连接真实禅道/TAPD或全局 DSH 外壳。本轮未提交、推送或发布。
