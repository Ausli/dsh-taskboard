# 外部任务同步（ZenTao / TAPD）

本功能对应 #48，支持 **禅道 REST API v1 的产品 Bug** 和 **TAPD Open API 的缺陷、需求、任务**。两者使用同一同步引擎；平台描述、认证方式、工作项类型和发现能力由 Provider 注册信息驱动。实际部署兼容性仍需联调确认；本轮未连接真实禅道或 TAPD。

## 使用

1. 打开看板设置，从左侧菜单选择「外部同步」，再选择禅道或 TAPD。原有隔离、模型、权限、调度及存储选项归入「通用设置」。切换菜单会保留未保存的表单内容。
2. 禅道填写安装地址，例如 `https://example.com/zentao`，不要包含 `/api.php/v1`；TAPD 默认 API 地址为 `https://api.tapd.cn`。
3. 禅道默认勾选「同步此登录账号的任务」，自动复用登录用户名，不需重复填写；要同步其他人的任务时取消勾选，再填写「任务处理人账号」（禅道 account）。TAPD 需单独填写处理人成员昵称。
4. 禅道填写并保存登录用户名、密码；TAPD 选择 Basic Auth（API 用户名/密码）或 Bearer Token（Access Token）。选择工作项类型。登录用户名和同步处理人可以不同，权限由登录用户决定。
5. 配置外部产品/项目 ID 到本地项目的映射，可添加多行。同一外部项目只允许映射一次。可先点击「发现外部项目」再从输入框候选项选择；TAPD 发现项目需要公司 ID 和成员昵称。发现操作使用当前表单，不会保存连接。
6. 可指定最早创建日期。首次导入只创建分配给该账号且不处于已配置结束状态的工作项。
7. 保存连接，然后测试、立即同步。新任务进入 Backlog，不自动启动 Agent。
8. 自动同步间隔为 0 时关闭；开启后可设为 5～1440 分钟。DSH host 必须运行，网页可以关闭。

禅道由 host 使用已保存的用户名、密码调用 `POST /api.php/v1/tokens` 获取 Token；同一操作中复用 Token。读取接口返回 HTTP 401/403 时重新登录并最多重试一次。生成的 Token 仅保留在操作实例内存，不写入任务。旧 Token 配置不再支持，需要重新填写并保存用户名和密码。

TAPD API 用户名/密码应使用企业 API 凭据，不是个人网站登录密码；Bearer 方式需自行获取和更新 Access Token，本功能不包含 OAuth 授权页面及自动刷新。所有凭据留空时仅在平台、地址、处理人及认证方式均不变时保留原值；切换平台/认证方式必须明确填写相应新凭据。同一平台、地址、处理人切换 Basic/Bearer 保持来源 ID，避免重复导入。

TAPD 的结束状态默认 `closed,resolved,done,rejected`。企业自定义工作流应修改「结束状态」原始值；自定义优先级通过「紧急/低优先级名称」映射。优先保留及使用 `priority_label`，不认识的值归为普通优先级。多处理人按分号拆分，精确匹配昵称，不使用子串匹配。

## 同步规则

- 唯一键由连接、外部项目、类型、外部 ID 组成。同一外部 ID 的 Bug、需求、任务互不冲突。外部 ID 不是本地任务 ID。
- 禅道完整分页扫描 `status=all`；TAPD 显式 `order=id desc`，串行按最后一条 ID 传递 cursor，避免深页数限制。两者都按内容快照增量写入，未使用修改时间增量水位。
- 没有内容变化的卡片不增加版本；详情显示来源内容最近变更时的同步时间，连接面板显示最近成功扫描时间。
- 标题、描述、优先级采用三方合并。本地未修改的字段随外部更新；冲突保留本地，任务详情可选择采用外部或保留本地。
- 进行中、待验收任务保留当前内容，外部差异显示为待处理冲突。进行中不可解决冲突。已完成、已取消任务仅更新来源的状态与处理人，不再累积内容冲突；已归档任务停止更新。
- 本地状态、认领、评论、检查清单、分支、模型和执行历史不会被同步覆盖。新卡继承创建时的看板默认模型、权限和隔离设置。
- 外部解决、关闭或转派只更新来源信息，不改变本地执行状态。外部删除、权限变化导致查不到的卡片继续保留。
- 删除的卡片会被忽略，不自动重建；可在设置中清除全部忽略记录。已清除但仍位于回收状态的卡片依然不会被复制。
- 修改映射只影响新卡。修改平台、服务器或同步账号会建立新的连接身份，应先评估重复导入范围。
- 同一连接只运行一轮同步；一轮所有项目和分页成功后才写入。失败不会根据缺失结果删除本地任务。
- HTTP 429、5xx 最多重试两次，限制等待；请求超时 30 秒，单轮上限 5 分钟。可手动停止同步，插件退出会中止请求。
- 禅道请求最小间隔默认 200 毫秒，可在设置中调整为 0～10000 毫秒（0 关闭节流）。补取详情前先排除无需导入的新记录；已有任务仍检查转派和关闭。

## 数据与凭据

连接、认证凭据和映射保存在活动 DSH_HOME 下的 `dsh-taskboard-external.json`，不会随看板数据目录迁移。此文件是 **host 专用明文配置**，使用当前用户文件权限保护，不能作为公开附件分享；不声称使用操作系统密钥库加密。不读取或迁移旧 Token 配置。

来源关联、删除忽略记录、最近同步结果、失败信息与尝试时间保存在看板账本的 `externalSync` 字段中，与任务在同一次原子写入中提交，随看板导出及数据目录迁移。失败仅保存错误状态，不提交本轮任务变化。已有有效用户名/密码连接中的非敏感运行记录会一次性迁入账本。

普通状态接口返回凭据保存标记，并仅回显明确标记为非敏感的登录用户名；密码和 Token 不返回、不进入任务导出。用户名和密码存储在上述 host 专用明文配置中。完整迁移外部连接需另行妥善迁移此配置文件。导入任务备份后，保留原连接 ID 的连接可继续匹配来源身份。

浏览器使用保存后的配置进行测试和同步；未保存的表单修改不会影响当前连接。

## 首期边界

当前只保存一个活动连接。暂不支持禅道需求/开发任务、附件下载、Webhook、状态回写、多连接并行和独立 Inbox。外部富文本会转为普通文本。禅道链接按标准 query 路由生成；TAPD 链接使用官方站点的工作项详情路由。定制或私有化路由部署需另行适配。

本地验证使用模拟 HTTP 禅道/TAPD 服务、真实 Provider、真实任务存储和真实路由。真实平台权限、Token 生命周期、自定义字段和安装路由兼容性仍须在目标环境确认。
