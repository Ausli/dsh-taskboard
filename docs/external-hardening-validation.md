# 外部同步审查修补验证

本轮在 issue #48 首期实现基础上修补审查问题；未连接真实禅道或 TAPD。

## 本轮变更

- 任务和非敏感同步元数据写入同一账本事务；连接文件仅保存连接配置和凭据。覆盖事务失败回滚、删除后重启不复活、导出保留忽略记录。
- 保存失败信息及最近尝试时间；成功后清除错误。错误状态自身无法落盘时明确报告。
- 冲突解决接口要求字段确实处于未解决冲突中。
- 已归档卡片停止更新；已完成、已取消卡片仅更新外部状态和处理人，不累积内容冲突。
- 禅道请求默认最小间隔 200 毫秒，可配置；过滤无关新记录后再按需请求详情。
- 映射删除按钮改为 36×36 像素图标按钮，与输入框底部对齐，包含可访问名称。
- npm 文档限定为中文/英文使用说明及 Provider 契约。

## 验证结果

- `npm run typecheck`：通过。
- `npm test`：37 个文件、468 个用例通过；新增 11 个存储、终态、冲突及节流验证用例。
- `npm run build`：通过，host/client 构建产物已更新。
- `npm pack --dry-run --json`：成功；docs 仅包含 external-sync.md、external-sync.en.md、external-providers.md。
- Chrome 无头浏览器：使用实际 SettingsModal、样式和 Provider 描述，验证菜单切换、认证表单、立即同步入口、窄屏无横向溢出及删除映射交互；未发现页面脚本错误。
- 三行映射的按钮宽高均为 36 像素，与输入框底部差值均为 0。

浏览器使用模拟配置服务；平台交互测试使用本地模拟 HTTP 服务。以上结果不代表真实部署的权限、工作流和安装版本兼容性验收。
